# Uniblox Checkout Rewards Service

Reliable ecommerce checkout and milestone coupon service for the Uniblox take-home.

## Prerequisites

- JDK 21
- Maven 3.9+

## Build and test

```bash
mvn verify
```

## Run locally

```bash
mvn spring-boot:run
```

The local service will run at `http://localhost:8080`.
